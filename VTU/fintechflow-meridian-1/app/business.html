Production checklist

Build for safe operations

  • Keep provider and API credentials on the server; never embed secrets in browser code.
  • Authenticate operators, authorize each action and enforce account-level limits.
  • Use idempotency for retries; verify webhook signatures and reject duplicate events.
  • Record references, amounts and state changes for audit and reconciliation.
  • Handle pending, failed, reversed and timed-out outcomes without reporting false success.
  • Test with provider-approved sandbox credentials, then enable production only after formal approval.
