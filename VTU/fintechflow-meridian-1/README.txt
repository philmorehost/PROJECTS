FINTECHFLOW UI DEMO

Quick offline preview:
  Open index.html in your browser.
  Use the Business tab or menu to open business.html.

Full interactive demo:
  Double-click start-demo.bat.
  It opens http://127.0.0.1:4173/ in your browser.

This is a visual demo only. Personal and business feature lists are a catalogue, not a claim that every service is live. Balances, rates, and payment confirmations are illustrative. No real financial transactions occur.

The VTU and API section is an integration concept only. Its routes and payloads are examples, not live endpoints; no API credentials or provider connections are included.

Images, styles, scripts, and pages are included in this folder.
If the browser blocks local file access, use start-demo.bat instead.
