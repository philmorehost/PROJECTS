How to update your website
Two ways to install v7.34 on ada-hairs.com.ng — pick whichever suits you.
Option 1
From your admin dashboard
Sign in to DGV7.0-SAAS as the super admin, open System Update Centre and press Install Update Automatically. The script downloads v7.34, backs up your files and database first, and rolls back on its own if anything fails.
No files to move. The update is applied for you, and the page shows the progress step by step.
or
Option 2
Automatic, from your control panel
Prefer it hands-free? In cPanel → Cron Jobs (Plesk and DirectAdmin work the same way) add one daily job. It checks for a release, installs it and e-mails you the result — no dashboard visit needed.
0 1 * * * /usr/local/bin/php /home/USER/public_html/bc-spadmin/cron_update.php >> /home/USER/ota_updates.log 2>&1
Copy the exact line from Super Admin → Cron Jobs — it already contains your own paths.
Either route installs v7.34. If you would rather do it by hand, download the package from your dashboard and upload it in cPanel → File Manager, then press Force Check on the update page.
