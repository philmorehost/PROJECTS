If an update goes wrong

  • Every replaced file is copied to a timestamped folder under storage/updates/backup/ before it is overwritten. Copy them back over the installation to roll back by hand.
  • The installed version is recorded in config/update-state.json. Deleting that file makes the installer-facing version report read 1.0.0 again.
  • Run php bin/doctor.php after an update; it checks the result rather than assuming it.
