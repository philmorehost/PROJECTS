For the site operator The provider says only “invalid key or domain” for every kind of mismatch, so check these in order — the first one that is wrong is the cause:
  1. Is the key complete? It is copied from the provider console; a missing digit or a stray space makes it an unknown key.
  2. Is it this licence? A key belonging to another project or another site is “unknown” to this one.
  3. Is the domain on the licence exactly buildroom.rccglp63yaya.org.ng? Domains are matched with www. ignored, but a different subdomain is a different licence.
  4. Is the licence active in the provider console? A suspended one is refused the same way.
  5. The key actually in use is the one in config/activation-key.php — shown above, masked. If it is not the key you expect, that is the whole problem.
  6. Can this host reach manager.pmhserver.name.ng over HTTPS at all?
